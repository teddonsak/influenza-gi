## 🌟 คุณสมบัติเด่น (Key Features)

### 1. หน้าลงทะเบียนหลักสำหรับผู้ใช้งาน (User Registration)
- **หัวข้อและข้อมูลโครงการ**: ระบุชื่อโครงการชัดเจน พร้อมแจ้งราคาพิเศษ **390 บาท / 1 เข็ม** (ครอบคลุมค่าแพทย์และอุปกรณ์)
- **ฟอร์มกรอกข้อมูล 5 ช่อง**:
  - คนที่ 1: **บังคับกรอก (Required)** สำหรับผู้ติดต่อหลัก
  - คนที่ 2 - 5: **ไม่บังคับกรอก (Optional)** สำหรับคนในครอบครัวหรือเพื่อนร่วมงาน
- **ระบบทำงาน 3 ขั้นตอน (Interactive 3-Step Flow)**:
  1. **หน้ากรอกข้อมูล**: มีปุ่ม `ขอดูผลงานก่อนส่งหน่อยเด้ 🧐`
  2. **หน้าแสดงตัวอย่าง (Preview)**: สรุปรายชื่อ คำนวณยอดเงินรวมอัตโนมัติ ($N \times 390$ บาท) พร้อมปุ่ม `อุ๊ย! พิมพ์ผิด ขอถอยไปแก้แป๊บ 🚗💨` และปุ่ม `ยืนยัน! จัดเต็มมาเลยพี่ 💉✨`
  3. **หน้าบันทึกสำเร็จ (Success)**: แสดงการ์ดสรุปใบจอง + พลุกระดาษฉลอง (Confetti) พร้อมปุ่ม `มีคนอยากโดนจิ้มเพิ่ม กดตรงนี้จ้า 🔄`

### 2. แดชบอร์ดสำหรับผู้ดูแลระบบ (Admin Dashboard — `/admin`)
- เข้าถึงผ่านปุ่มเมนู Admin หรือ URL `/admin`
- **สรุปตัวเลขสถิติภาพรวม (Metrics Summary)**:
  - จำนวนรอบการลงทะเบียนทั้งหมด
  - จำนวนผู้รับวัคซีนรวมทั้งหมด (คน)
  - ยอดเงินรวมทั้งสิ้น (บาท)
  - จำนวนคนเฉลี่ยต่อรอบ
- **ตารางแสดงข้อมูลละเอียด**: แสดงวัน-เวลาที่ลงทะเบียน (พ.ศ. 2569), รหัสการจอง, รายชื่อผู้ลงทะเบียน, จำนวนคน และราคารวม
- **ระบบค้นหาและกรองข้อมูล (Live Search)**: ค้นหาตามชื่อ, รหัสจอง หรือวันที่ได้ทันที
- **ส่งออกไฟล์ Excel (.xlsx)**: กดปุ่ม **"ดาวน์โหลดไฟล์ Excel (.xlsx)"** เพื่อรับรายงานตารางจัดรูปแบบเสร็จสมบูรณ์ทันที (Powered by SheetJS)

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend Framework**: React 19 + TypeScript + Vite
- **Styling & UI**: Tailwind CSS + Google Fonts (Prompt & Inter)
- **Icons**: Lucide React
- **Excel Generation**: SheetJS (`xlsx`)
- **Animation Effects**: Canvas Confetti
- **Storage**: LocalStorage Persistence (บันทึกข้อมูลแบบเรียลไทม์ ใช้งานได้ทันทีไม่ต้องติดตั้ง Database เพิ่มเติม)

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Getting Started)

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. รันในโหมด Development
```bash
npm run dev
```
เปิดบราวเซอร์ไปที่ `http://localhost:5173/`

### 3. Build สำหรับ Production
```bash
npm run build
```
